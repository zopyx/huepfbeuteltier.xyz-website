# Hüpfbeuteltier

Satirisches Lebensmodell als statische Website: Manifest, Mietrecht für Beuteltiere, Boxkarriere, Trainingsplan und ein Känguru-Index zum Selbsteinstellen.

Kein Build-Schritt. Reines HTML, CSS, JavaScript.

## Lokal

```sh
python3 -m http.server 8080
# http://localhost:8080
```

## Prüfen

```sh
python3 tools/check.py
```

## Deploy

Vercel, statisches Projekt (`vercel.json` im Root, `framework: null`).
